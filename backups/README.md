# Зашифрованные резервные копии

`*.dpapi` — off-router копии baseline с конфигурацией Xray и возможными
секретами подключения.

Файлы зашифрованы Windows DPAPI для текущей учётной записи пользователя.
Восстановление под другим пользователем или на другом компьютере не
гарантируется.

Не публикуйте и не отправляйте эти файлы. Обычный однокомандный rollback
использует снимок на роутере; этот каталог нужен при потере Entware-накопителя.
