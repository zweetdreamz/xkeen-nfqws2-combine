XKeen + nfqws2

Короткая памятка по независимому управлению Discord TCP, Discord Voice и YouTube: напрямую, через zapret или через VPN.

Что работает сейчас

Маршрут

Активен режим both: Discord TCP, Discord Voice и YouTube идут через отдельные Xray DIRECT outbounds, затем через nfqws2.

Роутер

KN-1011, XKeen/Xray Hybrid, WAN eth3, nfqws2-keenetic 1.2.4.

Discord

Web/TCP и сетевой путь Desktop Voice подтверждены. Xray выбирает Discord TCP только по доменам, без широкой IP-категории Cloudflare/Google; Voice — по UDP-портам. Качество звука проверяется самим приложением.

YouTube

TCP/TLS и HTTP работают. QUIC/HTTP3 нужно проверять реальным компьютером или телевизором.

Три режима каждого сервиса

DirectОбычный WAN, профиль nfqws2 для сервиса выключен.
ZapretОбычный WAN, профиль nfqws2 включён.
VPNИсходный VLESS outbound Xray, nfqws2 не обрабатывает сервис.
D
Discord TCPДомены Discord: сайт, API, CDN, QUIC
V
Discord VoiceГолос и STUN по UDP-портам
Y
YouTubeСайт, видео, QUIC

Переключить один сервис

cd /opt/root/keenetic-discord-nfqws2

sh set-service-route.sh discord-tcp   zapret --core auto --wan-interface eth3 --yes-router
sh set-service-route.sh discord-voice direct --core auto --wan-interface eth3 --yes-router
sh set-service-route.sh discord       vpn    --core auto --wan-interface eth3 --yes-router
sh set-service-route.sh youtube       zapret --core auto --wan-interface eth3 --yes-router

discord переключает Discord TCP и Voice вместе. Режимы остальных сервисов читаются из текущего состояния и сохраняются.

Каждый apply создаёт pre-apply snapshot, проверяет core и автоматически откатывается при ошибке.

Откат

Вернуть состояние перед последним применением:

cd /opt/root/keenetic-discord-nfqws2
sh rollback-last-change.sh

Вернуть исходный baseline:

sh rollback-to-baseline.sh

Показать актуальные указатели:

sh apply-discord-nfqws2.sh --show-snapshots

Перед ручным rollback создаётся rescue snapshot текущего состояния.

После перезагрузки

Повторный apply не нужен. Через одну-две минуты:

xkeen -status
/opt/etc/init.d/S51nfqws2 status
iptables-save -t mangle | grep NFQUEUE

Если /opt не смонтирован, сначала восстановите Entware/USB. Если /opt доступен:

/opt/etc/init.d/S05xkeen restart on
(cd / && /opt/etc/init.d/S51nfqws2 restart)

Диагностика

Общий read-only статус:

sh apply-discord-nfqws2.sh --status
sh apply-discord-nfqws2.sh --preflight --core auto --wan-interface eth3
sh scripts/diagnose-xkeen-router.sh

--status показывает discord_tcp_route, discord_voice_route и youtube_route.

Discord Desktop Voice:

sh scripts/diagnose-discord-voice.sh CLIENT_IP 30

Во время окна переподключитесь к voice-каналу. Для YouTube проверяйте старт, перемотку, длительное воспроизведение и отдельно телевизор.

Локальная web-панель

cd /opt/root/keenetic-discord-nfqws2
sh tools/router/xkeen_control_script.sh
/opt/bin/python3 /opt/xkeen-web/app.py

Откройте http://192.168.2.1:8088. Панель управляет XKeen и тремя режимами для Discord TCP, Discord Voice и YouTube. Установщик только создаёт приложение и не добавляет автозапуск.

Полный apply показывает этапы и сохраняется в истории по дате. Из истории можно вернуть snapshot до выбранной операции. После успеха выполняются проверки служб и конфигов. HTTP/TLS с LAN-устройства запускаются во вкладке «Диагностика»; QUIC и Discord Voice проверяются вручную.

Во вкладке «Автоподбор» можно выбрать конкретный BAT-файл Flowseal и проверить только его конфиг. Список файлов появляется после кнопки «Проверить обновление». Проверка обновления, запуск подбора и применение профиля остаются тремя отдельными действиями.

Панель не имеет пароля. Она привязана к LAN-адресу; не пробрасывайте порт 8088 в интернет.

Обновление nfqws2 и Xray

Переход на nfqws2-keenetic 1.3.1 и Xray 26.10.17 не требует изменений в скриптах: блобы YouTube совпадают с закреплёнными SHA-256, переменные nfqws2.conf и _startup_args сохранены. Пакет 1.3.1 добавляет --fastpath-workaround=auto.

Перед обновлением Xray запустите «Проверить роутер» в панели: проверка «Xray 26.10+ совместимость» найдёт proxySettings и addressPortStrategy во freedom, которые новый Xray не загружает.

После обновления nfqws2 перепроверьте YouTube и Discord: новый бинарник иначе собирает TLS на роутерах с аппаратным fastpath.
