# Документация

Здесь описан код в корне проекта. Наличие установки, диагностического доступа
и рабочей сети проверяется на конкретном устройстве.
Требуются XKeen 2.1+ поколения 2.x, Xray и Python 3.12+ на роутере.
Для VPN-нод и чекеров нужен Xray 26.10.31+ поколения 26, для чекеров — curl с HTTP2.
Версии 2.0, standalone и Mihomo не поддерживаются.
Состояние установленного устройства проверяется отдельно, не по этим файлам.

Основная схема: Direct по умолчанию, VPN по правилам и одна вручную выбранная
нода. Чекеры маршрута/ресурсов, контроль IP, браузерная диагностика и подбор
стратегий имеют разные задачи. Контроль IP не переключает ноды и не запускает
подбор. Его включение и одобрение допустимых адресов выполняются вручную.
