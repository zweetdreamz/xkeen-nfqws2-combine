# VPN-ноды

Одна активная нода меняет общий outbound `vless-reality`.
Все правила Xray с этим тегом используют выбранное подключение, не только
карточки панели. Независимые чужие outbounds не переписываются.
В реестре до 16 нод. Нужны Xray 26.10.31+ поколения 26, ctypes и Linux prctl.
Автобалансировки и автоматического выбора резервной ноды нет.

## Действия

| Кнопка | Результат |
|---|---|
| Добавить и проверить | Сохранить резервную ноду и результат пробы, без активации |
| Проверить / Проверить все | Фоновые последовательные пробы, рабочий Xray не меняется |
| Редактировать | Имя или source резервной ноды; пустой source сохраняет секреты |
| Сделать активной | Проверка, private backup, замена общего outbound и рестарт XKeen/Xray |
| Восстановить прошлую ноду | Recovery после незавершённого переключения |
| Проверить текущую ноду | Выходной IPv4/IPv6 и HTTPS через работающий Xray; нужны подготовленные чекеры |
| Одобрить наблюдаемый IP | Явно сохранить свежие допустимые IP текущего подключения |
| Сохранить контроль и IP | Сохранить допустимые адреса, выбранные family, интервал и включение мониторинга |

Настройки активной ноды не заменяются редактированием; rename разрешён.
Секреты обратно в форму не загружаются. После изменения source старый health сбрасывается.

## Форматы

Карточка показывает endpoint, протокол, транспорт, TLS/Reality и заданные
flow/fingerprint/SNI. Отсутствующие дополнительные поля не показываются.
UUID, пароли, ключи Reality и исходная ссылка в карточку/API не передаются.

VLESS/Trojan URI или JSON outbound: TCP/RAW, WS, gRPC, XHTTP/SplitHTTP,
TLS/Reality и поддержанные поля безопасности.
Hysteria2: hy2:// или hysteria2://, auth, SNI/ALPN, pinning.
Полный finalmask передавайте JSON; диалекты ports/mport/obfs не угадываются.
insecure=1, дубли/конфликтующие aliases, неизвестные/неприменимые поля и
ссылки на другую ноду через proxySettings/dialerProxy отклоняются.

## Проверка отдельной ноды

Изолированный Xray слушает localhost SOCKS; HTTPS-пробы идут через выбранный
outbound с remote DNS и ожидаемыми204/200. Proxy env/NO_PROXY/.curlrc
не должны превращать это в direct fallback.
Успех подтверждает эти запросы, не все приложения и протоколы.

Есть таймауты и RSS-watchdog96MiB; это не жёсткий kernel memory limit.
Worker управляет только собственным тестовым PID. После SIGKILL могут
остаться private temp-файлы, но тестовый Xray не должен жить бессрочно.

## Контроль работающей ноды и выходного IP

Проверка отдельной ноды не доказывает, что действующий Xray уже использует её
настройки или выходит с нужного IP. Карточка **Контроль активной VPN-ноды и IP**
проверяет именно рабочий процесс и его полный outbound, затем наблюдает IP
через выделенный VPN SOCKS. Direct fallback и проверки резервной ноды отсутствуют.

Сначала явно подготовьте API/SOCKS в «Диагностике». Выполните свежую проверку,
одобрите IPv4/IPv6 либо введите допустимые адреса вручную, выберите контролируемые
family и сохраните настройки. До одобрения всех выбранных family монитор
включить нельзя. По умолчанию он выключен, интервал — 5 минут, допустимо 1..1440.

Ожидаемые IP связаны с ID ноды и параметрами подключения. Первое наблюдение,
смена подключения и ошибка не принимают новый IP автоматически. IP VPN-сервера
не равен выходному IP. IPv6 без результата остаётся непроверенным.

После внешнего рестарта Xray, команды «Перезапустить» в блоке XKeen, ребута или изменения
его конфигов требуется повторная явная подготовка доступа. Монитор только
наблюдает и сохраняет историю: он не меняет ноду, службы, маршруты или стратегии
и не закрепляет IP у провайдера. Полный порядок и статусы:
[чекеры и VPN/IP](../usage/route-checker.md).

## Ошибки и хранение

Drift активного outbound требует явного принятия текущего конфига.
При ошибке активации выполняется откат. Незавершённый recovery блокирует
изменения/проверки; GET не запускает восстановление.

Каталоги0700, файлы0600. Отдельные пределы VPN:20 activation backups,
32 записи корзины,64 версии,16MiB на каталог. Pending recovery source защищён.
Это не политика30дней для снимков маршрутов и не UI восстановления удалённых нод.
