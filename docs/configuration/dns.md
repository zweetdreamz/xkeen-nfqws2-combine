# DNS домашней сети

На «Управлении» два ручных режима для Home:

| Режим | Назначение |
|---|---|
| DNS over VLESS | DnsVlessMain → Xray192.168.2.1:15355 → текущая VPN-нода →1.1.1.1:53 |
| DoH на роутере | DnsProfile0 → уже настроенные HTTPS-резолверы Keenetic |

Переключается только назначение DNS-профиля Home. Сами профили,
гостевая сеть и индивидуальные профили устройств не переписываются.
Xray/nfqws2, VPN-нода и профили Zapret не перезапускаются/не меняются.
DNS самого роутера остаётся прежним. Свой DoH браузера этим не управляется.

## Применение

Нажмите нужный режим и подтвердите сохранение. Команда Keenetic сохраняет
все текущие изменения running-конфигурации, не только DNS: не оставляйте
несогласованные правки в другом интерфейсе во время операции.

Назначение проверяется повторным чтением. Эта проверка не доказывает
резолвинг у каждого клиента: после переключения откройте новый сайт на
устройстве Home. Автоматического failover при отказе VPN в первой версии нет.

## Защита и откат

Операция использует общий project lock и фиксированные команды профилей.
До изменения записывается приватный dns-last-change.json в state_root.
Ошибка команды/проверки/сохранения запускает возврат прежнего назначения.
Если операция прервана, можно явно выбрать прежний режим для восстановления;
другая смена блокируется до завершения recovery.
Откат версии панели не возвращает DNS-назначение: при необходимости сначала
выберите прежний DNS-режим или восстановите его в настройках Keenetic.

Неизвестные профили, смешанный plaintext/DoH, изменения остальных DNS-настроек
или proxy_router не off приводят к отказу, а не перезаписи чужих конфигов.
Реализация рассчитана на существующие Home/DnsVlessMain/DnsProfile0.
При недоступном VPN переход в DoH не требует соединения с VPN или работающего
диагностического API Xray, но требует доступных Entware/XKeen2.1+ и native CLI.

## CLI

Из каталога установленного проекта:

```sh
python3 -P tools/router/dns_mode.py --status
python3 -P tools/router/dns_mode.py --set doh --yes-router
python3 -P tools/router/dns_mode.py --set vless --yes-router
```

GET /api/dns только читает. POST /api/dns/doh или /api/dns/vless
с JSON {"confirm":true} запускает обычное фоновое задание панели.
