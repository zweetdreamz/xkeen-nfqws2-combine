# Панель XKeen Control

## Требования

Keenetic с Entware, Python3.12+, XKeen2.1+ поколения2.x и Xray.
Для VPN-нод и чекеров нужен Xray26.10.31+ поколения26, curl с HTTP2,
ctypes/Linux prctl, fcntl, mkfifo и dd.
Секреты и резервные копии не включаются в пакет.

## Разделы

- Управление: маршруты сервисов, DNS Home, конфигурации, история и откат.
- VPN-ноды: общий outbound, отдельная проверка, редактирование и активация.
- Диагностика: службы/конфиги, браузерные пробы, маршруты, ресурсы и VPN/IP.
- Автоподбор: YouTube, Discord TCP и Voice.
- Расписание: проверки YouTube и Discord TCP с автоматическим подбором/откатом.
- Уведомления: ntfy, тема, необязательный токен, события и тест.
- Импорт: descriptor стратегии и версии профилей.

## Выкатка и откат версии панели

Из корня проекта на компьютере:

```sh
sh tools/dev/deploy.sh --dry-run
sh tools/dev/deploy.sh
```

Пакет формируется по tools/dev/deploy-manifest.txt. Dry-run проверяет пакет,
версию устройства, синтаксис, занятость панели и показывает заменяемые файлы.
Не устанавливает проект, но загружает временный пакет на роутер.

Deploy сохраняет прежние файлы в /opt/etc/xkeen-web-backups, останавливает
только панель, устанавливает код и проверяет HTTP-ready и сетевые инварианты.
Ошибка запуска возвращает прежний код. Xray/nfqws2 не перезапускаются.
После обновления перезагрузите страницу через Ctrl+F5.

Откат последней поставки кода через SSH на роутере:

```sh
sh /opt/root/keenetic-discord-nfqws2/tools/router/rollback-xkeen-web.sh
```

Это не откат маршрутов/DNS/профилей. Для них используйте соответствующие
операции панели и пригодные снимки.

## Супервизор панели

Init: /opt/etc/init.d/S99xkeen-web. Команды start/stop/restart/status.
Он следит только за HTTP-панелью, с ограниченной задержкой перезапуска.
PID supervisor и HTTP worker различаются. Служебные логи ограничены.

Для установки init из каталога проекта на роутере:

```sh
/opt/etc/init.d/S99xkeen-web stop
sh tools/router/xkeen_control_script.sh --install-init
/opt/etc/init.d/S99xkeen-web start
```

Установщик сохраняет предыдущий init. Переключение init выполняйте только
при отсутствии активных заданий; в случае ошибки восстановите его копию.

## Доступ и ограничения

По умолчанию HTTP слушает LAN192.168.2.1:8088. Не публикуйте порт в интернет.
Панель рассчитана на одного пользователя в доверенной LAN. POST требуют
same-origin и X-XKeen-Control:1. Повреждённое состояние и pending recovery
блокируют изменения. Настройки соединений не возвращают пароли/UUID/ключи.

Проверки после применения выполняются автоматически. Результаты находятся
в диагностике; ошибки и предупреждения дублируются в журнале операции.

Read-only smoke с компьютера:

```sh
sh tools/dev/smoke-panel.sh --host 192.168.2.1 --port 8088 --yes-router
```

Он выполняет HTTP GET, но не меняет настройки и не проверяет качество голоса,
QUIC или воспроизведение видео. Их проверяют отдельно в приложениях.
