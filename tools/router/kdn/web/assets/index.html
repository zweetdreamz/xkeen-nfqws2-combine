«Проверить» запускает отдельный временный Xray через выбранную ноду и не меняет рабочий VPN. Только кнопка «Сделать активной» после вашего подтверждения перезапустит XKeen/Xray; перед этим создаётся backup и при ошибке выполняется откат. nfqws2 не перезапускается.

Добавить VPN-ноду

Поддерживаются VLESS, Trojan и Hysteria2: ссылка или один JSON outbound Xray. Сложные параметры Hysteria2 (обфускация, port-hopping) вводите через JSON. Секреты сохраняются на роутере с правами 0600 и не возвращаются в список.

Автоподбор стратегий

Актуальные general*.bat временно проверяются на роутере. Меняется только проверяемый профиль; остальные TCP/QUIC/UDP-профили сохраняются. Ручной и плановый режимы используют одинаковые пробы: Discord HTTPS + Gateway WebSocket, YouTube HTTPS + транспорт + QUIC. Voice требует подтверждения звука.

Выберите файл, чтобы проверить только его конфиг. Список появится после «Проверить обновление».
Safe отдельно меняет repeats, out-range, TCP pos/seq и QUIC repeats. Extended добавляет ограниченные сочетания и смешивание BAT-компонентов. С выбранным BAT-файлом вариации строятся от его профиля, а сам профиль проверяется первым. Порядок остальных кандидатов каждый раз новый. Подбор временно перезапускает только nfqws2; Xkeen не вызывается. Сервис должен заранее находиться в режиме Zapret.
